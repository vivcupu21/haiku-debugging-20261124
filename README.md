One haiku about debugging, written for the
[Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)
bounty on make.fun.

## The haiku

> Cursor blinks at three
> the last log line swears it lies
> so the bug was mine

Three lines, 5-7-5 syllables, 76 characters. A cursor blinking at three in
the morning, a log line that lies, and a last line that turns the blame
back on the debugger.

## How it runs

`main.py` (Python 3.13, standard library only) copies `entry.txt` verbatim
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

```sh
python3 main.py
```
